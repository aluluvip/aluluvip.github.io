折腾篇：VsTV —— 10MB 的电视直播播放器

一个不到 10MB 的安卓 APK，把电视盒子变回「能好好看电视」的设备：
原生组播直连、多源自动合并、7 天回看、老人模式，还能给外语节目实时翻译中文字幕。

项目地址：github.com/vesaaa/vstv（MIT，1487 star，最新 2.8.2）

一、先说清楚它是什么

VsTV 是一个直播播放器，不是「电视 App 合集」，更不是「免费看电视神器」。

它自己不内置、不提供任何直播源。装完之后是一片空白，你得自己往里填直播源地址（M3U、TXT 订阅、运营商组播地址都行）。这一点作者在 README 里写得很重，还把免责声明放在最后一条：

应用不内置、不提供、不分发任何直播源或节目内容；用户需自行导入并仅使用已获得合法授权的地址。

所以它的正确用法是：你原本就有 IPTV 订阅、或者自己搭了 tvgo / rtp2httpd 这类转播服务，然后需要一个好用的播放器。想找”免费看全世界的台”的，这项目帮不了你。

二、它凭什么值得单独写一篇

电视盒子上的直播软件我见过不少，绝大多数是同一个毛病：拿手机 App 的思路做电视。遥控器要按七八下才能换台，界面塞满广告和”推荐位”，安装包动辄五六十兆，低配盒子上开机要转半分钟。

VsTV 的取舍完全相反：

  • 安装包不到 10MB，针对 S905 这类低配盒子的内存占用做过优化；
  • 没有广告，不需要谷歌服务，U 盘拷进去就能装；
  • 为遥控器重做了交互：上下换台、左右切线路、长按确认键切直播源，几乎不用进菜单；
  • 原生组播，udp://、rtp:// 地址直接播，不需要 udpxy 那种转发服务。

最后这条是很多播放器的分水岭。运营商 IPTV 的高清/4K 频道基本都是组播，要先把组播转成 HTTP 才能播，中间多一层就多一层丢包和延迟。VsTV 直接接组播，自动拿系统组播锁、加大接收缓冲，画面花屏和卡顿的情况明显少。

三、装哪个包

每个版本发四个 APK，选错了要么装不上，要么功能对不上：

安装包 适合谁 说明
vstv-<版本>-arm.apk 默认选这个 绝大多数电视、盒子、手机，桌面名 VsTV
vstv-<版本>-arm-av3a.apk 要听菁彩声的 多了 AV3A（Audio Vivid）软解，体积更大，可直接覆盖 arm 版
vstv-<版本>-x86_64.apk 电脑上的安卓模拟器 不含菁彩声软解
vstv-<版本>-HarmonyOS.apk 华为智慧屏等 包名不同，桌面名「Z视介」，和常规版数据不互通

装的时候两个坑：

  1. Android 8 以上要允许安装未知应用，否则应用内更新点了没反应（更新包下载完了但装不上）。
  2. HarmonyOS 包和常规包不要混装，数据不互通，来回覆盖会丢配置。

四、直播源怎么加：四种方式，最后一种很贴心

第一次打开会自动弹「添加直播源」，给四条路：

方式 适合的场景
自动添加 局域网里有 tvgo（16677 端口）或 rtp2httpd（5140 端口），几秒扫出来
手机扫码 地址很长，或者源文件在手机里；扫电视上的码，在网页里填完推送过去
输入地址 地址短，愿意用遥控器敲
请求协助 自己不会弄，屏幕上出一个 4 位数字，家人在自己手机上远程帮你填

「请求协助」这个设计值得单独说。 给爸妈装电视软件，最痛的一步永远是”你把地址发我，我帮你填”——微信发一串 http 开头的长链，那边点不动、复制不全、粘贴失败。VsTV 把它做成：电视上显示 4 位数字，你在自己的 VsTV 里选「分享直播源」，输入这 4 位，电视上确认一下就好了。

支持的源格式

  • M3U：#EXTM3U + #EXTINF 标准格式，支持 catchup 回看模板和请求头；
  • TVBox / 影视仓风格 TXT：分组名,#genre# + 频道名,地址，支持一个频道多条线路（地址1#地址2）和分辨率后缀；
  • tvgo：自己小主机 / NAS 上跑的直播服务，支持自动发现；
  • rtp2httpd 播放列表：直接填它的 m3u 地址，列表里的相对路径会自动补全。

支持的协议

播放器基于 Media3（ExoPlayer），按地址自动识别协议；服务端实际格式和推断不一致时还会换一种方式重试：

协议 地址特征 备注
UDP / RTP udp://、rtp:// 原生组播，无需转发
HLS .m3u8 IPTV 最常见，可切多条音轨
DASH .mpd MPEG-DASH
Smooth Streaming .ism 微软平滑流
RTSP rtsp:// 含运营商 RTSP 回看
单文件直链 .mp4、.mkv 渐进式播放

硬解扛不住时，内置的 mediax（基于 FFmpeg 的扩展软解）会自动兜底，对 H.265 / HEVC 的老片子兼容性提升明显。

五、遥控器上到底怎么操作

这一节看着无聊，但决定老人能不能自己用：

操作 遥控器 手机 / 平板
换台 上 / 下键，或数字键直接选台 上下滑动
切换线路 左 / 右键 左右滑动（回看时是快进快退）
打开选台列表 确认键 单击
打开快捷菜单 菜单键，或长按下键 双击
快速切换直播源 长按确认键 长按约 0.8 秒
返回 返回键（键盘 ESC 也行） 返回手势

设置页在 2.7 版重做过：左边菜单、右边内容，九个分类（直播源、节目单、播放、界面、精选与合并、AI 字幕、网络、高级、关于），菜单上移动就能预览，按右键进入、左键返回。比原来 “连按好几下才进到某一项” 强太多。

六、几个真解决问题的功能

多源合并，线路挂了自动换

添加多个直播源后，同名频道（比如三个源里都有「CCTV1」）会自动合并成「线路 1 / 2 / 3」，某条线路打不开自动试下一条，并记住能用的那条。免费源三天两头失效，这个功能基本是刚需。

七天回看

适配运营商常见的 catchup 模板，最多回看 7 天，能拖动进度、快进快退、一键回直播。用的是源里的回看参数，不占本地空间。

精选 + 只看精选（老人模式）

长按确认键把常看的台加进「精选」，再打开「只看精选」，从此界面里只有那十几个台，换台也只在精选里循环。给长辈用这个，比教他”按菜单找分类”有效一百倍。

分屏与小窗

左右分屏或四宫格，最多同时看四路（比如一边球赛一边新闻）。手机/平板切到别的应用会自动小窗继续播。

AI 字幕

这是 2.7 版最大的新功能：把外语节目实时翻译成中文字幕，中文节目也能直接出字幕。两种后端：

  • TVGO 本地翻译（推荐）：用你自己 NAS / 小主机上开了 AI 翻译的 tvgo，不用密钥、不花钱，支持普通话、粤语、英语、日语、韩语。它走局域网，不经过任何云服务。
  • 阿里云百炼：能自动识别节目语言，但要自己申请 API Key，并且地域必须选「华北2（北京）」，国际站的 Key 不能用。按收听时长计费，不看外语节目时记得关掉。

几个使用限制要知道：

  • 开启后画面会比直播晚 3–8 秒（「字幕提前量」可调），否则字幕和声音对不上；
  • 分屏、DASH、RTSP 源暂不支持 AI 字幕；
  • 字幕样式、大小、位置、是否同显原文都能调。

七、网页配置：比遥控器打字舒服多了

同一局域网里，用手机或电脑打开 http://电视IP:1616，就能改直播源、节目单等设置，和电视上是同一份配置。地址和二维码在「设置 → 网络」里能看到。

这条对折腾党很实用：改一次源不用举着遥控器戳十分钟。注意这个页面依赖公共 CDN（jsDelivr 之类），网络不通的话页面会打不开。

八、几个已知的坑

现象 原因 / 处理
频道一直转圈 先左右键换线路；再拿手机/电脑打开同一个地址，确认源本身没死；要特定 UA 的源要在添加时填请求头；需要代理的源去设置里配代理
画面卡、掉帧 快捷菜单 →「解码与码流」看解码方式。显示”FFmpeg 软解”说明硬解不支持这个格式，4K / H.265 10bit / 60 帧软解多半算不动——这是盒子性能限制，换 1080p 线路
HDR 画面发灰发白 设备 HDR 处理与片源不匹配，属于系统层面问题
组播地址播不了 电视/盒子必须接在 IPTV 网络上（光猫 iTV 口，或路由器配好 VLAN），普通宽带网段里播不了组播
提示”直播源还没更新好” 到更新时间但下载失败，会先用上次的频道列表，新列表在后台继续下载
ASS / SSA 字幕 暂不支持（WebVTT、SRT、DVB、PGS、CEA-608 支持）

九、几点判断

适合装的：

  • 家里有运营商 IPTV，但受不了运营商那个难用的机顶盒界面；
  • 自己有小主机 / NAS 跑着 tvgo、rtp2httpd，需要一个轻量播放器；
  • 给长辈装电视，需要”只看那几个台”的极简模式；
  • 常看外语节目，想要不花钱的本地实时字幕。

不太适合的：

  • 想找免费直播源的——这软件不提供，也不该这么用；
  • 电视是 Android 5 以下的古董机；
  • 需要 ASS 字幕、或者对 HDR 有严格要求的（受设备和片源限制）；
  • 完全不想碰配置文件的人。

最后一句正经话：这类软件的价值在”播放器”这一层，不在”内容”这一层。自己准备好合规的源，它就是个很好用的播放器；指望它替你解决内容来源，那方向从一开始就错了。
